# GUIで使うGit

[全体の案内へ戻る](../README.md)

旧版で扱っていたGUI操作を、個人の画面やパスに依存しない手順に整理しました。ページへの既存リンクを保つため、`old/README.md` に置いています。

GitクライアントやエディターのGit機能でも、操作の基本はコマンドと同じです。ボタン名や配置は製品・バージョンによって異なるので、次の操作名を目印にしてください。

## 既存リポジトリを使う

1. 共有先でリポジトリのURLをコピーする。
2. クライアントの「Clone／複製」を選ぶ。
3. URLと保存先を指定して、複製する。
4. クローン先を開き、コミットの記録名義を確認する。

新規リポジトリを作る「Init／初期化」は、既存リポジトリを取得するCloneとは別の操作です。

## 変更を記録する

1. ファイルを編集して保存する。
2. 変更一覧から差分を開き、意図した変更か確認する。
3. 記録するファイルや行を「Stage／ステージ」する。
4. 変更の目的が伝わるメッセージを書いて「Commit／コミット」する。
5. 履歴画面で記録された内容を確かめる。

クライアントによっては、ステージとコミットを一度の操作で行う設定があります。どの変更がコミットに含まれるかを実行前に確認します。

## リモートと共有する

- 「Fetch／取得」：リモートの履歴を取得する。
- 「Pull／取得して統合」：取得した履歴を現在のブランチへ統合する。
- 「Push／送信」：ローカルのコミットをリモートへ送る。

「Sync／同期」が複数の操作をまとめて行う場合もあります。個別の操作との違いはクライアントの説明を確認してください。

公開前には [個人情報と履歴の確認](../PRIVACY.md)を行います。画像を共有する場合は、表示中のアカウント、ファイルパス、履歴、他のウィンドウにも気を配りましょう。
